# Smart Sales Report

Applicazione Python per automatizzare l'analisi di file di vendita CSV ed Excel e generare automaticamente un report Excel professionale.

## Funzionalità

- Importazione di file CSV e XLSX
- Pulizia automatica dei dati
- Rimozione dei duplicati
- Analisi dei valori mancanti
- Riconoscimento automatico delle colonne
- Calcolo automatico del fatturato
- Calcolo dei principali KPI
- Analisi delle vendite per prodotto
- Analisi delle vendite per categoria
- Dashboard Excel automatica
- Grafici automatici
- Statistiche descrittive
- Controllo della qualità dei dati
- Apertura automatica del report finale

## KPI calcolati

Il programma può calcolare automaticamente:

- Fatturato totale
- Quantità totale venduta
- Numero di operazioni
- Valore medio per operazione
- Prodotto con il maggior fatturato

## Tecnologie utilizzate

- Python
- Pandas
- OpenPyXL
- Tkinter
- Microsoft Excel
